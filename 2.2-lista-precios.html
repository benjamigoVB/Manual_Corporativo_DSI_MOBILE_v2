2.2 Lista de Precios

Consulta inmediata de tarifas unitarias de repuestos, filtros por categoría y exportación a Excel y PDF en movilidad operativa para el asesor comercial.

Producción Estable Actualizado Marzo 2026 Versión 1.0.0
ℹ️

Información de Tarifas Oficiales y Sincronización: Los precios reflejan las tarifas corporativas autorizadas vigentes sincronizadas en tiempo real desde el ERP central DSI-NET. Las tarifas incluyen impuestos según normativa y aplican estrictamente a la lista comercial asignada al asesor comercial en campo para asegurar coherencia en auditorías de facturación.

1. Consulta de Precios y Tarjetas de Repuestos

El buscador superior localiza repuestos mediante coincidencia de texto predictivo por nombre comercial o código de parte directo. Cada tarjeta estructurada despliega la descripción técnica homologada, código de inventario en almacenes, unidad de medida oficial (UND / PZA) y el precio unitario en moneda nacional (S/.).

Opción Lista de Precios en el menú
Pantalla inicial con catálogo de repuestos y precios vigentes

2. Filtros de Búsqueda Avanzada

La opción Filtros despliega una consola modal multicriterio para segmentar instantáneamente miles de registros sin recargar la pantalla. Permite cruzar variables de Clase, Familia de repuestos, Marca del equipo, Modelo específico o Procedencia de manufactura para asegurar una cotización ágil y certera frente al cliente en campo. Su operatividad mantiene el mismo criterio dinámico que el módulo de reporte de stock.

Opción para aplicar filtros
Ventana de filtrado dinámico multicriterio

3. Exportación a Formato Excel

Al accionar la opción de acción Excel en color verde, el módulo local compila la vista activa (incluyendo cualquier filtro aplicado a demanda) y genera una hoja de cálculo nativa (.xlsx). El archivo preserva tipos de datos numéricos y encabezados estándar para su inmediata remisión por correo corporativo o almacenamiento local.

Opción exportar a Excel
Escoger la aplicación para abrir el documento
Vista del documento exportado (.xlsx)

4. Exportación a Formato PDF / Vista de Impresión

La opción PDF en color rojo procesa y genera un documento formal estandarizado en formato A4 con membrete institucional de DSI SAC, identificador de tarifa, sello de vigencia y pie de firma para entrega formal ante clientes, habilitado para impresión remota o despacho digital.

Opción exportar a PDF
Hoja membretada y reporte documental formal para clientes
